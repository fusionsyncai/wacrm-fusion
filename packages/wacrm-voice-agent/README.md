# wacrm-voice worker

LiveKit Cloud agent for WhatsApp voice calls. Uses **LiveKit Inference** (no separate Deepgram/OpenAI/Cartesia keys on the worker).

Full setup: [docs/voice-agents.md](../../docs/voice-agents.md)

## Deploy (once per LiveKit Cloud project)

```bash
brew install livekit-cli   # if needed

cd packages/wacrm-voice-agent
cp .env.example .env
# Edit .env — set VOICE_CALLBACK_SECRET (same as wacrm / Vercel)

lk cloud auth              # pick the LiveKit project for this account
lk agent create            # secrets: choose .env when prompted
```

If create fails with `project does not match agent subdomain []`, delete `livekit.toml` and retry.

## Redeploy after code changes

```bash
lk agent deploy
```

## Local dev (optional)

```bash
pip install .
python -m wacrm_voice_agent.agent download-files
cp .env.example .env.local   # fill LIVEKIT_* + VOICE_CALLBACK_SECRET
python -m wacrm_voice_agent.agent dev
```

## Files

| File | Commit? | Notes |
|------|---------|--------|
| `.env` | No | Secrets for `lk agent create` / local dev |
| `.env.example` | Yes | Template |
| `livekit.toml` | No | Generated by `lk agent create` (subdomain + agent id) |
| `livekit.toml.example` | Yes | Reference only |
| `.dockerignore` | Optional | Often generated by `lk agent create` |

## Verify

```bash
lk agent status
lk agent logs
```

Expect `"agent_name": "wacrm-voice"` in logs — must match wacrm **Settings → LiveKit voice → Worker agent name**.
